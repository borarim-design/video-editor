# 폰트 라이선스와 출처

이 폴더의 TTF는 모두 **무료로 상업적 사용이 가능한** 글꼴을 받아
한글 음절 전체(U+AC00–D7A3) + 자모 + ASCII + 주요 문장부호로 **서브셋**한 파일입니다.
서브셋은 원본의 파생물이므로 아래 라이선스가 그대로 적용됩니다.

## SIL Open Font License 1.1 요약
- 자유롭게 사용·복제·수정·재배포할 수 있습니다(상업적 사용 포함).
- 수정한 폰트를 재배포할 때는 **OFL 1.1 라이선스를 함께 포함**해야 하며, 폰트 자체를 단독으로 판매할 수는 없습니다.
- 전체 라이선스 전문: https://scripts.sil.org/OFL

## G마켓 산스
- 지마켓(현 SSG)이 무료로 배포하는 글꼴로, 상업적 사용이 허용됩니다.
- 재배포 시 출처를 밝히는 것을 권장합니다.

문의: 폰트별 원본 저장소의 라이선스 문서를 참고하세요.
